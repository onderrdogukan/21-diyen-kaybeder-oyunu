# *Oyun Teorisi ve Yapay Zeka: 21 (Nim) Algoritması*

HTML5, CSS3 ve saf (Vanilla) JavaScript kullanılarak geliştirilmiş, literatürdeki "Nim Oyunu" varyasyonuna (21 Game) dayanan algoritmik bir web uygulamasıdır.
Projenin temel amacı, harici bir framework kullanılmadan durum yönetimini (state management) sağlamak ve modüler aritmetik tabanlı optimal kazanma stratejisini(Game Theory)
bir yapay zeka modeline entegre etmektir.

## Temel Özellikler
* **Matematiksel Yapay Zeka (AI):** Oyunun "Zor (Hard)" seviyesi, rastgelelikten uzak, tamamen modüler aritmetiğe (hedef sayı 21, adım limiti 3, mod 4) dayalı
   optimal kazanma stratejisi (winning strategy) uygular. 
* **Olasılık Tabanlı Zorluk Seviyeleri:** Kolay ve orta seviyelerde, yapay zeka optimal hamleyi yapma ihtimalini Math.random() tabanlı olasılık hesaplamaları ile
   sınırlandırarak insan benzeri hata yapma toleransı gösterir.
* **Dinamik DOM Manipülasyonu:** Oyun geçmişi (history box), kullanıcı ve bilgisayar hamlelerini anlık olarak DOM üzerinde günceller ve
   overflow durumunda otonom scroll yönetimi (scrollTop) sağlar.
* **Modern Kullanıcı Arayüzü:** CSS Variables (Değişkenler), Flexbox mimarisi ve Keyframes animasyonları kullanılarak tasarlanmış, tam duyarlı (responsive) ve
   olay güdümlü (event-driven) arayüz.

## Kullanılan Teknolojiler
* **Geliştirme:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Algoritma:** Game Theory, Optimal Winning Strategy (Nim)
* **Tasarım:** CSS Keyframes, CSS Variables, Responsive Layout
